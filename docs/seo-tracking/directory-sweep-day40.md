## 4. TATO membership — **a business decision, not a checklist item** *(differs from the original plan)*

The original plan assumed Trust Tours already has TATO membership and just needed a URL check. That's not the case — Ombeni confirmed there's no existing membership. Joining TATO is a formal application with **membership fees**, not a free profile fill-in, so I'm not treating it as something to "complete" today.
